# FM-MCMC: Estimating Orbital Parameters of Direct Imaging Exoplanets Using Neural Networks

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

This repository provides the official implementation for the paper: **"Estimating Orbital Parameters of Direct Imaging Exoplanet Using Neural Network"**.

We propose a new flow-matching Markov chain Monte Carlo (FM-MCMC) algorithm for estimating the orbital parameters of exoplanetary systems, particularly those with a single exoplanet. This method combines the speed of deep generative models with the accuracy of traditional sampling.

## 📝 About the Paper

Traditional Bayesian methods for exoplanet orbital fitting, like PTMCMC or Nested Sampling, are accurate but computationally expensive. Our approach, FM-MCMC, first uses flow matching posterior estimation (FMPE) to efficiently constrain the prior parameter range and then employs MCMC to accurately infer the posterior distribution.

In our case study on **$\beta$ Pictoris b**, our model achieves a massive speed-up while maintaining comparable accuracy:
* **77.8 times faster** than Parallel Tempered MCMC (PTMCMC).
* **365.4 times faster** than nested sampling.

Our method also achieved the highest average log-likelihood, demonstrating superior sampling efficiency and accuracy.

## ✨ Key Features

* **⚡️ High Speed:** Reduces inference time from hours (35.4h for Nested Sampling, 7.5h for PTMCMC) to **under 6 minutes**.
* **🎯 High Accuracy:** Produces posterior distributions statistically consistent with traditional methods (PTMCMC, Nested Sampling).
* **⚙️ Hybrid Architecture:** Leverages a Continuous Normalizing Flow (CNF) trained via flow matching to generate high-quality proposals for a PTMCMC sampler.
* **Scalable:** Well-suited for processing the massive datasets expected from future exoplanet surveys.

## 🚀 How It Works (Methodology)

The FM-MCMC framework consists of two main stages:

1.  **Training Stage:**
    A flow-matching-based neural network is trained on a large dataset (16 million simulated exoplanetary systems). The network learns to map observational data (time-series $\Delta$RA and $\Delta$Dec) to the eight orbital parameters ($\{a, e, i, \omega, \Omega, \tau, \pi, M_T\}$).

2.  **Inference Stage:**
    * **Step 1 (Initial Proposal):** The pre-trained neural network receives the real observation data (e.g., for $\beta$ Pictoris b) and rapidly generates high-quality initial proposals.
    * **Step 2 (Refinement):** These proposals are injected into the PTMCMC algorithm. This "warm start" drastically reduces the burn-in phase to just 1% of the traditional requirement, allowing the sampler to converge quickly to the accurate posterior distribution.



### 2\. Train a New Model

You can train the model from scratch using the provided scripts.

**Step 1: Generate Training Data**
We use the open-source `orbitize!` package to generate the training data. The script will sample 16 million orbital configurations from the prior ranges specified in our paper.

```bash
python generate_data.py --num_samples 16000000 \
                        --output_file data/training_data.h5
```

**Step 2: Run Training**
Train the flow network using the `train.py` script. The model architecture consists of an embedding network and a flow network with 21 residual blocks.

```bash
python train.py --data_path data/training_data.h5 \
                --model_save_dir models/
```

Training was completed in just 22 minutes on an NVIDIA RTX 4090 GPU.

## 📊 Data

  * **Training Data:** The model was trained on 16 million simulated single-planet systems analogous to $\beta$ Pictoris b. Data is generated by sampling from the priors in our paper.
  * **$\beta$ Pictoris b Data:** The observational data for $\beta$ Pictoris b used in this study is based on published astrometry data.
